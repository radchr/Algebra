# AGENTS.md — Інструкції та Архітектура Проєкту "Інтерактивний Кисельов"

## 1. Мета та огляд проєкту
Створення сучасного інтерактивного двомовного (українська / англійська) освітнього застосунку на базі класичного підручника-задачника **А. П. Кисельова «Задачи и упражнения к элементам алгебры» (4-е видання, 1931 р.)**.

Оригінал підручника міститься у файлі `Zadachi i upr. k eliemientam al - Nievidomii.pdf` (118 сторінок сканованого тексту без текстового шару).

---

## 2. Ключові принципи та вимоги

### 2.1. Мова та локалізація
* **Мови застосунку:** Українська (основна) та Англійська (перемикач `UK` / `EN`).
* **Термінологічна адаптація:** Заборонено калькувати застарілу радянську термінологію 1930-х років.
  - *«Алгебраическое знакоположение»* ➔ *«Алгебраїчні вирази та буквені позначення»* / *«Algebraic Notation and Expressions»*
  - *«Относительные числа»* ➔ *«Додатні та від'ємні (раціональні) числа»* / *«Signed Numbers / Directed Numbers»*
  - *«Составное именованное число»* ➔ *«Складене іменоване число»* / *«Compound Denominate Number»*
  - *«Расположенные многочлены»* ➔ *«Впорядковані многочлени (за спаданням/зростанням степенів)»* / *«Ordered Polynomials»*

### 2.2. Математична точність та символьне ядро (SymPy CAS)
* Відповіді учня **не порівнюються як простий текст**.
* Для валідації використовується `sympy`:
  - Перевірка алгебраїчної еквівалентності: `simplify(user_expr - expected_expr) == 0`.
  - Підтримка різних допустимих форм запису (наприклад, `(x + 1)(x - 1)` і `x**2 - 1`).
  - Звірка з офіційним розділом відповідей підручника (сторінки 94–117 PDF).

### 2.3. Дидактика та педагогіка (7 клас / STEM)
* Застосування підходу **POEM** (*Predict – Observe – Explain – Mission*) та 3-рівневих сократівських підказок (*Scaffolding*):
  1. **Рівень 1 (Концептуальний):** натяк на сутність ідеї (без формул).
  2. **Рівень 2 (Формульний):** натяк на потрібну формулу чи проміжний крок.
  3. **Рівень 3 (Повний розбір):** покроковий розв'язок у стилі Feynman (інтуїтивні моделі, без псевдонаукового слопу).

## 3. Технічний стек та інструменти

* **Менеджер пакетів:** `uv` (`pyproject.toml`, віртуальне оточення `.venv`).
* **Мова:** Python 3.11+.
* **Інтерфейс:** `marimo` — реактивні блокноти та інтерактивні веб-дашборди (`marimo run` / `marimo edit`).
* **Символьна математика:** `sympy`.
* **Робота з PDF:** `pypdfium2` для рендерингу сторінок у 300 DPI зображення.
* **Мультимодальне розпізнавання (OCR + Translation):** `google-genai` (Gemini 2.5 Flash / Pro Vision) зі строгими Pydantic-схемами.
* **Візуалізація:** `altair`, `matplotlib`, в перспективі — `d3js` / `p5js` для динамічних візуальних маніпулятивів (Algebra Tiles, координатна пряма, балансирів).

## 5. Правила для агента (Rules of Engagement)

1. **Цілісність коду Marimo:** Дотримуватися реактивного DAG: чисті допоміжні функції (`pure functions`) виносити в модулі `src/algebra_kiselev/`, а в клітинках Marimo тримати лише реактивний стан та візуальні елементи `mo.ui.*`.
2. **Двомовність за замовчуванням:** Кожна додана задача повинна мати поля `text_uk` та `text_en`, а також коректний LaTeX у `formula_latex`.
3. **Захист від слопу (`anti-slop`):** Пояснення повинні бути чіткими, лаконічними, без штучно нагромаджених термінів чи абстрактної "води".
4. **Перевірка розв'язків:** Кожна задача перед додаванням у продакшн-датасет повинна бути автоматично розв'язана і верифікована через `solver.py` (SymPy) проти розділу відповідей Кисельова.
