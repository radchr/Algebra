# 📐 Інтерактивний Кисельов — Математика 7 клас

[![Deploy to GitHub Pages](https://github.com/radchr/Algebra/actions/workflows/deploy.yml/badge.svg)](https://github.com/radchr/Algebra/actions/workflows/deploy.yml)
[![Live Demo](https://img.shields.io/badge/Live_Demo-GitHub_Pages-brightgreen?style=flat&logo=github)](https://radchr.github.io/Algebra/)

Сучасна українська інтерактивна освітня платформа на базі класичних підручників **А. П. Кисельова**, адаптована до чинної програми 7 класу (НУШ) та синхронізована зі шкільними підручниками **А. Г. Мерзляка** (Алгебра та Геометрія).


---

## 🌟 Ключові можливості платформи

* **🌐 Веб-платформа на GitHub Pages:**
  * Працює автономно в браузері (без важких серверів) на телефонах, планшетах і ПК.
  * Блискавичне відкриття (технологія *Lite Embed* та чистий клієнтський JS).
* **🕹️ Жива геометрія (JSXGraph):**
  * Експериментальні моделі евклідової геометрії: дитина може рухати вершини, промені, змінювати кути й на власні очі бачити збереження геометричних інваріантів (наприклад, сума суміжних кутів завжди $180^\circ$).
* **💡 Розумний тренажер задач з алгебри (№ 1–29):**
  * Покрокова сократівська система підказок (*Scaffolding*):
    1. *Рівень 1:* Концептуальний натяк на ідею (без формул).
    2. *Рівень 2:* Формульний крок.
    3. *Рівень 3:* Повний розбір розв'язання у стилі Фейнмана.
  * Автоматичне збереження прогресу учня в `localStorage`.
* **🎬 Відео-пояснення з YouTube:**
  * Наочні геометричні та алгебраїчні анімації в стилі 3Blue1Brown (Manim), вбудовані через оптимізовані фасади (0 КБ стороннього трафіку до кліку учня).
* **📄 Видавничі робочі зошити у PDF:**
  * `zadachi_1_29_ukr.pdf` — чисті формулювання для роботи ручкою в зошиті без спойлерів.
  * `vidpovidi_1_29_ukr.pdf` — детальний розбір, верифікований системою комп'ютерної алгебри **SymPy**, з поясненням історичних помилок друку видання 1931 року.

## 🚀 Локальний запуск та розробка

### 1. Інтерактивні цифрові застосунки Marimo
```bash
# Запуск інтерактивного цифрового підручника геометрії:
uv run marimo run app_geometry.py

# Запуск інтерактивного задачника з алгебри:
uv run marimo run app.py
```

### 2. Тестування та перевірка якості коду (Ruff & Pytest)
У проєкті налаштовано єдиний стандарт чистоти коду через **Ruff**:
```bash
# Перевірка коду лінтером (із автоматичним виправленням):
uv run ruff check . --fix

# Форматування всього коду проєкту за стандартом PEP8:
uv run ruff format .

# Перевірка форматування без внесення змін:
uv run ruff format --check .

# Запуск усіх модульних тестів:
uv run pytest
```

### 3. Статична веб-платформа docs/
```bash
# Запустити локальний сервер для статичних HTML-сторінок:
python -m http.server -d docs 8000
```
Після цього відкрийте у браузері: [http://localhost:8000](http://localhost:8000).
